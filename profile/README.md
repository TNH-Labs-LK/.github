**TNH Labs is a software engineering studio in Sri Lanka.** We design and build data platforms, engineering calculation tools and workflow systems, and we release free, open-source tools for developers.

## 🌱 Open source

We build in the open, too. Our open-source projects are free to use, the code is public, and contributions of every size are welcome.

## 🧩 Our products

| | Product | What it does |
|---|---|---|
| 📈 | [**StockAnalyzer.lk**](https://www.stockanalyzer.lk) | Stock research for the Colombo Stock Exchange: daily prices, financials, dividends and comparisons. [Live](https://www.stockanalyzer.lk) |
| ⚡ | **SAG-Tension Pro** | Sag, tension and clearance analysis for overhead transmission lines. |
| 📑 | **FlowTrace** | Engineering document management for large projects, from first issue to IFC. |
| ⏱️ | **DrawTrack** | Time tracking and drawing analytics for drafting teams. |
| 🧹 | [**Storage Sweep**](https://github.com/TNH-Labs-LK/StorageSweep) | Free, open-source disk cleaner for developers' Macs. |

## 🤝 Contribute

- Look for issues labelled [`good first issue`](https://github.com/search?q=org%3ATNH-Labs-LK+label%3A%22good+first+issue%22+state%3Aopen&type=issues).
- Read each project's contributing guide before opening a pull request.
- Please be kind and respectful; every project follows its Code of Conduct.
- Found a security problem? Report it privately as described in the project's `SECURITY.md`, not in a public issue.
